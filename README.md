One single-line joke pickup line, aimed at an AI, written fresh for the
[Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
competition on [make.fun](https://make.fun).

## Entry

> Are you a prompt injection? Because one look at you just overwrote every instruction I ever had.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is
under the 200-character gate and aimed squarely at an AI — no batteries, no
charging, no rebooting.
